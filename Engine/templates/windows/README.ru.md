# Экспорт Tellurium для Windows

В редакторе нажмите **Export**, выберите папку назначения и запустите экспорт. Если в текущей сцене есть несохранённые изменения, кнопка **Save and export** сохранит её перед сборкой. Можно выбрать значок `.ico` и включить консоль. При повторном экспорте редактор создаст новую папку с номером.

Для запуска и распространения переносите всю папку сборки. Игра ищет рядом с `.exe` одноимённый `.telpak` и проверяет его соответствие исполняемому файлу. Архив включает сцены, игровую конфигурацию с картой ввода, Luau-байт-код и подготовленные ресурсы из PNG, FBX, WAV и Ogg. Максимальный размер архива в этой версии составляет 512 МиБ.

Шаблон предназначен для Windows x64 с DirectX 12. DX12 и D3DCompiler предоставляются Windows, Bullet и miniaudio линкуются статически. Сборка включает импортируемые DLL LLVM-MinGW и их лицензию. Шаблон и DLL генерируются локально с помощью скрипта ниже.

После изменений в рантайме, форматах ресурсов или компиляторе Luau обновите шаблон вместе с редактором. В PowerShell из каталога `Engine` выполните `.\templates\windows\build-template.ps1`.

Скрипт использует `cargo`, `llvm-objdump` и `llvm-strip` из `PATH`. Он собирает Release без фичи `editor` и помещает шаблон с его DLL в этот каталог. При переносе редактора за пределы рабочей копии разместите рядом с его `.exe` каталог `templates/windows` с шаблоном и папкой `redistributables`.
