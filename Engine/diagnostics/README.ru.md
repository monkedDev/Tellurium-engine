# Диагностика и горячая перезагрузка

Откройте **Console** во время **Play**, чтобы видеть FPS, время кадра, число сущностей, память Luau, вызовы отрисовки и время физики и ECS. Для асинхронной физики показано время последнего завершённого пакета шагов Bullet.

Редактор включает клиент Tracy 0.12.2. В [Tracy Profiler 0.12.2](https://github.com/wolfpld/tracy/releases/tag/v0.12.2) подключитесь к `127.0.0.1:8086` во время игры. Дорожки CPU включают этапы Rust, Bullet, записи команд DX12 и Present. График **DX12 GPU frame (ms)** вычисляется по таймстампам GPU. Для отдельного рантайма профилирование включается фичей `profiling`. Шаблон экспорта собирается без клиента Tracy.

## Горячая перезагрузка в редакторе

- `.luau`. Редактор заменяет функции активного экземпляра и сохраняет сущность, значения глобальных переменных и состояние ECS. `on_start` повторно не вызывается. Для локальных переменных замыканий верните данные из `on_snapshot()` и примите их в `on_restore(value)`. Подписки на ввод можно объявить в верхнем уровне скрипта или обновить в `on_reload()`. Доступные глобальные поля отображаются в **Inspector → Live script state**.
- `.png`. Редактор повторно импортирует текстуру и заменяет её содержимое под существующим дескриптором. Материалы продолжают ссылаться на тот же дескриптор.
- `.telsc`. Редактор подхватывает изменения текущей сцены с диска. Несохранённые правки имеют приоритет. В **Game View** новая сцена устанавливается после успешной подготовки.
- `Engine/graphics-cpp/shaders/mesh.hlsl`. В рабочей копии движка редактор следит за штатным HLSL. Успешная компиляция заменяет объект PSO DirectX 12 при сохранении устройства, swap chain, root signature и ресурсов. Ошибка компиляции оставляет рабочий шейдер активным.

## Luau-плагины редактора

Положите скрипт в `plugins/` в корне проекта и откройте проект. Плагин должен вернуть функцию. Редактор передаёт ей имя события и строковый аргумент через свою шину событий. Возвращённый текст появится в **Console**, а `nil` означает отсутствие сообщения.

```luau
return function(event, value)
    if event == "SceneOpened" or event == "ScriptReloaded" then
        return event .. " " .. value
    end
end
```

События включают `SceneOpened`, `SceneChanged`, `EntitySelected`, `SceneReloaded`, `ScriptReloaded`, `TextureReloaded` и `ShaderReloaded`. Каждый плагин работает в отдельной Luau VM с квотами и получает только данные события. `plugins/` исключается из экспорта игры.
