# Tellurium engine

**Альфа-тест. Стабильная работа не гарантируется.** Форматы проектов, API Luau и возможности редактора могут измениться.

Tellurium — игровой движок с ядром на Rust, нативным рендерингом DirectX 12 и скриптами на Luau. В редакторе есть три встроенных проекта для проверки 2D-ввода, физики Bullet и пространственного звука.

## Запуск редактора

Для сборки на Windows x64 нужны Rust, Cargo и совместимый компилятор C++17. Запустите команды из корня репозитория.

```powershell
cd Engine
cargo run --locked -p tellurium-runtime --features editor
```

В менеджере проектов откройте пример через **Built-in samples → Open sample**, затем нажмите **Play**.

Для Windows-экспорта сначала соберите шаблон рантайма по [инструкции](Engine/templates/windows/README.ru.md). У проекта также есть [описание архитектуры](ARCHITECTURE.ru.md) и [руководство по диагностике и горячей перезагрузке](Engine/diagnostics/README.ru.md).
