# 23.2 3D-звук

Математический расчёт пространственных характеристик звука.

## Возможности

- **Затухание** — уменьшение громкости на основе расстояния между Listener и Source.
- **Панорамирование** — левый/правый канал в зависимости от относительного положения источника и слушателя.
- **Доплеровский эффект** — изменение частоты звука при относительном движении источника и слушателя.

## Реализация

- Все расчёты выполняются через **cxx мост**.
- Rust передаёт позиции Listener и Source в C++ аудио-библиотеку.
- C++ библиотека возвращает итоговые параметры микширования.
