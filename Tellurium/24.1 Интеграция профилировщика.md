# 24.1 Интеграция профилировщика (Tracy / Pix)

## Возможности

- Подключение мощного C++ профилировщика (например, **Tracy**) через **cxx мост**.
- Сквозной таймлайн кадра: видно, где застрял поток физики в C++, где ждёт главный поток Rust, сколько времени занимает рендеринг на GPU.
- Профилировщик охватывает оба мира — Rust и C++ — через общие метки и зоны профилирования на границе cxx.
