# 01 Rust Ядро

Фундамент движка Tellurium. Вся игровая логика, управление памятью, ECS, Luau рантайм и загрузка ресурсов реализованы на Rust. Никакого прямого доступа к GPU или физике из Rust — только через [[02.3 cxx мост|cxx мост]] в [[02 C++ модуль]].

## Подразделы

- [[01.1 Управление памятью]] — ownership / borrowing, арены, пулы
- [[01.2 Luau рантайм]] — одна VM, корутины, песочница, квоты
- [[01.3 ECS]] — сущности, компоненты, системы, мир
- [[01.4 Менеджер ресурсов]] — загрузка, кэширование, дескрипторы
- [[01.5 Безопасность и защита]] — safe Rust, cxx граница, изоляция Luau

## Связи

- Зависит от: [[Платформа]] (окно, ввод, файловая система, потоки, время)
- Вызывает через [[02.3 cxx мост|cxx мост]]: [[02 C++ модуль]] (графика, физика)
- Запускает: [[01.2 Luau рантайм]] для игровой логики
- Поддерживается: [[05 Редактор]] (инструменты разработки)
- Связано с: [[26 Системы ввода и контекстных действий]] (генерация событий Actions на основе карты действий)
