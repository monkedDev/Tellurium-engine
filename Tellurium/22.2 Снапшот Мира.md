# 22.2 Снапшот Мира (World Snapshot)

Возможность «заморозить» текущее состояние ECS-мира со всеми `EntityId`, позициями и переменными Luau-скриптов.

## Процесс создания снапшота

1. Обход всех сущностей в мире ECS.
2. Сериализация каждого компонента через serde.
3. Сохранение связей между сущностями (родитель -> дочерние узлы в иерархии сцены).
4. Запись состояния Luau VM: активные корутины, значения переменных скриптов.
5. Сборка в единый бинарный/текстовый файл сохранения (`.telsave`).

## Восстановление мира

- Десериализация компонентов.
- Восстановление связей `EntityId`.
- Пересоздание скриптовых компонентов с привязкой к Luau.

## Использование

- Запись в файл сохранения (сохранение игры).
- Передача по сети (сетевая синхронизация, реплеи).
