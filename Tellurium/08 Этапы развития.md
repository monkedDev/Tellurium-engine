# 08 Этапы развития (кратко)

Дорожная карта Tellurium Engine.

1. **Ядро:** Rust, ECS, Luau runtime, базовое окно и ввод.
2. **Мостик и графика:** cxx границы, базовый рендер (очистка экрана, треугольник).
3. **Ресурсы:** загрузка текстур, мешей, шейдеров, материалов.
4. **Физика:** подключение PhysX / Bullet через C++, события столкновений в ECS.
5. **Редактор:** менеджер проектов, Hierarchy, Inspector, Project, Scene View, Game View, Console.
6. **Полировка:** полный цикл кадра, оптимизация, песочница скриптов, документация API.
