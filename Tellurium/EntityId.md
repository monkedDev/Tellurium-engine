# EntityId

Идентификатор сущности в ECS Tellurium.

## Назначение

Сущность (Entity) — лишь идентификатор (`EntityId`), без собственных данных. Все данные хранятся в компонентах.

## Принципы

- Уникальный идентификатор внутри мира ECS (`World`)
- Используется для связи между Rust ECS и C++ объектами (физические тела, меши на GPU)
- Каждый объект в C++ хранит `EntityId` для сверки с живыми сущностями при очистке
- Используется как слабый дескриптор на стороне Luau вместо прямых ссылок на ресурсы
