# 01.5 Безопасность и защита

Политики безопасности Tellurium Engine на уровне ядра и границ между языками.

## Принципы

- **Безопасный Rust:** вся логика движка пишется в `safe Rust`. Блоки `unsafe` допускаются только в минимальных местах FFI-границ и должны быть обёрнуты в безопасные абстракции.
- **Граница cxx:** все переходы Rust → C++ типизированы библиотекой `cxx`; неявных приведений и неконтролируемого доступа к памяти нет.
- **Изоляция Luau:** скрипт не может вызвать системный API напрямую. Все операции с файлами, сетью, устройствами ввода проходят через движковый шлюз с проверкой прав.
- **Проверка указателей на границе:** C++ не сохраняет сырые указатели на объекты Rust; взаимодействие происходит через идентификаторы, дескрипторы или `cxx::SharedPtr`.
