# 05.5 Горячая перезагрузка (Hot Reloading)

Система бесшовной перезагрузки ресурсов и скриптов без перезапуска редактора или игры.

## Отслеживание изменений

[[01.4 Менеджер ресурсов]] на Rust подписывается на системные уведомления ОС за изменениями файлов:
- `.luau` — исходный код скриптов
- `.png` и другие форматы текстур
- `.telsc` — файлы сцен

При изменении файла ресурс помечается как «требует перезагрузки» и ставится в очередь на начало следующего кадра.

## Luau-скрипты (State Preserving)

1. Resource Manager уведомляет Scripting модуль об изменении `.luau` файла.
2. Scripting компилирует новую версию скрипта в отдельном байт-коде, не останавливая текущую Luau VM.
3. Для каждого `ScriptComponent` выполняется замена реализации функций на новые.
4. **State Preserving:** текущее состояние переменных скрипта сохраняется. Игра не сбрасывается, сущности не пересоздаются.

## Текстуры и шейдеры (C++ Render)

1. Resource Manager загружает обновлённые данные файла в Rust.
2. Через [[02.3 cxx мост|cxx мост]] отправляется команда в C++ графический модуль.
3. C++ модуль загружает новые данные в существующие GPU-ресурсы без пересоздания конвейера.
4. Текстура замещается на лету, шейдер перекомпилируется.
