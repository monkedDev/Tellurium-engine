# 04.1 Мета-файлы (.telmeta)

Для каждого исходного ассета Tellurium автоматически создает сопутствующий текстовый файл конфигурации с расширением `.telmeta` (например, `texture.png.telmeta`).

## Содержимое

- Уникальный глобальный идентификатор ресурса (GUID)
- Настройки импорта (тип фильтрации текстуры, компрессия звука)
- Хэш версии файла для отслеживания изменений

## Важность

Файлы `.telmeta` обязательны для систем контроля версий (Git), так как гарантируют, что у всех разработчиков в команде ассеты настроены одинаково.
