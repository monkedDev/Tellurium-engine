# input

Папка каталогов движка Tellurium, содержащая систему ввода.

## Назначение

- Карты действий (Action Mapping): Digital, Analog/Axis, Pass-through
- Контексты ввода (Input Contexts): GameplayContext, UIContext, приоритеты
- Обработка осей и скан-кодов через платформенный модуль
