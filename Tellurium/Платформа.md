# Платформа

Абстракция платформы и ОС в Tellurium Engine. Нижний уровень архитектуры (уровень 0).

## Ответственность

- Окно (создание и управление окном приложения)
- Ввод (клавиатура, мышь, геймпад, тач)
- Файловая система (чтение, запись, отслеживание изменений)
- Потоки (multithreading الأساس)
- Время (delta time, кадры)

## Связи

- Часть: [[00 Tellurium Engine]] (уровень 0 в [[00 Tellurium Engine|Слои архитектуры]])
- Используется: [[01 Rust Ядро]] (базовые примитивы)
- Связано с: [[26 Системы ввода и контекстных действий]] (сырые события ОС → Actions)
- Реализуется на: Rust (абстракция над ОС)
