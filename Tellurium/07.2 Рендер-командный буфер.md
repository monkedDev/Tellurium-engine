# 07.2 Рендер-командный буфер (Render Command Buffer)

## Проблема

Если на каждом кадре гонять трансформации тысяч объектов из Rust в C++ по одному через отдельные cxx-функции, производительность упрётся в накладные расходы на FFI-вызовы, даже несмотря на нулевой оверхед cxx.

## Решение

- На этапе **Render preparation** (шаг 5 жизненного цикла кадра) Rust формирует один линейный массив (буфер) сырых данных: ID меша, ID материала, матрица трансформации, флаги видимости.
- Этот массив передаётся в C++ **одним вызовом** в виде среза данных `&[RenderCommand]`.
- C++ модуль за один проход забивает командные буферы DirectX 12 / Vulkan и отправляет их на GPU.
- Для частых обновлений (трансформации) используется буфер констант (constant buffer / uniform buffer), который обновляется блочно, а не по объекту.
