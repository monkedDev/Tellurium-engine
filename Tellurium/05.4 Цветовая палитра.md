# 05.4 Цветовая палитра Tellurium

Единая цветовая палитра интерфейса редактора. Все элементы используют только эти цвета, чтобы сохранить визуальную консистентность.

| Элемент | HEX | Название | Роль |
|---|---|---|---|
| [[Deep Tellurium]] | `#0B0E14` | Глубокий теллур | Основной фон окон, таймлайна и графов |
| [[Metalloid Slate]] | `#161B26` | Сланцевый полуметалл | Боковые панели, инспектор, вкладки |
| [[Brittle Silver]] | `#2A3345` | Хрупкое серебро | Границы, разделители, неактивные иконки |
| [[Tellurium Flame]] | `#00F0D2` | Пламя теллура | Главный акцент: выделение, Play, связи графа |
| [[Chalcogen Blue]] | `#00A3E0` | Халькогеновый синий | Вторичный акцент: подсказки, папки ассетов |
| [[Pure Quartz]] | `#E2E8F0` | Чистый кварц | Основной текст |

Акцентный `#00F0D2` зарезервирован для интерактивных и активных состояний, чтобы не размывать визуальную иерархию.
