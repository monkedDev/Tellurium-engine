# 05.1 Менеджер проектов

Стартовое окно Tellurium, аналогичное Godot. Запускается перед открытием редактора.

## Доступные действия

- **Выбрать проект** — открыть существующий проект из списка.
- **Почитать о проекте** — просмотреть описание проекта, версию движка, путь к папке, дату последнего открытия.
- **Создать проект** — ввести имя, выбрать папку, шаблон (2D / 3D / пустой), создать структуру каталогов и файл проекта.
- **Сканировать проект** — указать папку на диске; движок ищет файлы проекта (например, `.tprj` или `project.toml`) и добавляет их в список.
- **Удалить проект** — удалить запись из менеджера (опционально — с удалением файлов проекта с диска после подтверждения).
- **Открыть проект** — загрузить проект и перейти в редактор.
- **Экспорт (Export/Build)** — выбор целевой папки на Windows, настройка параметров билда (Debug/Release, иконка приложения, включение консоли отладки) и запуск пайплайна сборки финального приложения.

## Файл проекта

Проект описывается конфигурационным файлом (например, `project.tprj` или `project.toml`). Содержит: имя проекта, версию Tellurium, графический бэкенд (DX12/Vulkan), пути к ассетам и сценам, список последних сцен, настройки редактора.
