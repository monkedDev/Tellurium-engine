# 06 Жизненный цикл кадра (Game Loop)

Последовательность шагов за один кадр в Tellurium Engine.

## Шаги кадра

1. **Input** — сбор событий ввода через Enhanced Input System (клавиатура, мышь, геймпад, тач), трансляция в Actions на основе текущего контекста.
2. **Pre-update** — системы подготовки, вызов `on_start` для новых скриптов.
3. **ECS update** — системы игровой логики; вызов Luau `on_update` для скриптовых компонентов. Запуск/планирование параллельного шага физики (Fixed Update) в отдельном потоке.
4. **Physics step (синхронизация)** — не блокирующий шаг симуляции в главном потоке. Чтение последних готовых трансформаций из параллельного физического потока через двойную буферизацию и запись их в ECS-компоненты `Transform`. Новый шаг физики запускается асинхронно для следующего кадра.
5. **Render preparation** — сборка камер, источников света, материалов, видимых объектов.
6. **Render draw** — команды рендеринга передаются через [[02.3 cxx мост|cxx мост]] в C++ графику и исполняются на GPU.
7. **Present** — замена front/back буферов, вывод кадра на экран.
8. **Post-frame** — очистка временных ресурсов, публикация событий конца кадра, подготовка к следующему кадру.
