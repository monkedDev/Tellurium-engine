# templates/windows

Папка каталогов движка Tellurium, содержащая предкомпилированный шаблон рантайма для Windows.

## Назначение

- Предкомпилированный легковесный шаблон `tellurium_runtime.exe`
- Инициализация ядра Tellurium (Rust) и загрузка C++ модуля через cxx мост
- Считывание привязанного или лежащего рядом файла .telpak
- Запуск игры без редактора, без исходного кода и без инструментов разработки
