# 01.3 ECS (Entity Component System)

Entity Component System — центральная часть логики Tellurium. Сущность — лишь идентификатор, компоненты — данные, системы — логика.

## Компоненты

- **Сущность (Entity)** — лишь идентификатор (`EntityId`), без собственных данных.
- **Компоненты** — простые структуры данных (POD-подобные), хранятся в массивных хранилищах по типам.
- **Системы** — Rust-функции, которые обходят запросы (queries) по набору компонентов и изменяют данные.
- **Мир (World)** — центральный контейнер всех сущностей, компонентов и систем.
- **Скриптовый компонент (`ScriptComponent`)** — привязывает сущность к Luau скрипту и хранит дескриптор состояния скрипта.
- **События ECS** — отдельная шина сообщений: столкновения, триггеры, ввод, события жизненного цикла сущности.
