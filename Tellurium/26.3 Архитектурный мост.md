# 26.3 Архитектурный мост (Platform ↔ Core ↔ Luau)

1. **Модуль platform (Rust)** собирает сырые прерывания ОС Windows (события оконной петли Win32 / GLFW).
2. **Модуль core** транслирует сырые скан-коды клавиш в активные Actions на основе текущего контекста и публикует их в шину событий Event Bus.
3. **Luau-скрипты** подписываются не на клавиши, а на события действий. API из Luau выглядит как безопасный коллбэк: `input.bind_action("Jump", on_jump)`.
