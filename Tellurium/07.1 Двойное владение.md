# 07.1 Двойное владение (Double Ownership)

## Проблема

Компоненты (`Rigidbody`, `Collider`, `Transform`) лежат в Rust ECS, а физические тела живут внутри C++ (PhysX / Bullet). Аналогично — меши и текстуры: дескрипторы в Rust, данные на GPU в C++. Если сущность в ECS удаляется, но не синхронизировать удаление с C++, в физическом мире останется «призрачное» тело, которое будет продолжать сталкиваться с объектами.

## Решение

- Система событий жизненного цикла ECS. При удалении `RigidbodyComponent` или `ColliderComponent` в Rust, система отправляет команду через [[02.3 cxx мост|cxx мост]] на удаление соответствующего объекта из физического мира C++.
- Удаление компонента в Rust считается «источником истины» (source of truth); C++ физика не удаляет тела по своей инициативе, только по команде из Rust.
- Для рендеринга: при удалении компонента `MeshRenderer` в Rust, команда на освобождение меша/материала на GPU отправляется в C++ рендер.
- Каждый объект в C++ хранит идентификатор сущности ECS (`EntityId`), чтобы при очистке можно было свериться с живыми сущностями.
