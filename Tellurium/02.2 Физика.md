# 02.2 Физика

Физический движок Tellurium на основе готового C++ решения (PhysX или Bullet), инкапсулированного в обёртку.

## Принципы

- ECS-система физики на Rust передаёт позиции, коллайдеры и параметры тел в C++ физику.
- События столкновений возвращаются из C++ в Rust через [[02.3 cxx мост|cxx мост]] и публикуются в шину событий ECS.
- Физические компоненты (`Rigidbody`, `Collider`) хранятся в Rust ECS; соответствующие физические тела — в C++, связаны по идентификатору сущности (`EntityId`).
