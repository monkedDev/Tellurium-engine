# 03.3 Инстансирование сцен

Сцена в Tellurium может быть упакована как ресурс (PackedScene) и инстанциирована в другой сцене несколько раз.

## Принципы

- Каждый инстанс получает свой корневой узел и независимую копию дерева узлов.
- Позволяет повторно использовать сложные сцены (уровни, префабы, окружение) без дублирования данных.
