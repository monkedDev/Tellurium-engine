# Event Bus

Шина событий движка Tellurium.

## Назначение

Централизованная шина сообщений для взаимодействия между подсистемами движка, скриптами и плагинами без прямой зависимости друг от друга.

## Принципы

- Подсистемы публикуют события в шину, другие подписываются на них
- Асинхронная обработка событий
- Плагины не вызывают функции ядра напрямую — только публикуют события в Event Bus
- Разделение на Немедленные события (Immediate Events) и Отложенные события (Deferred Events)
