# 02.1 Графический конвейер

Графический абстракционный слой Tellurium. Единый безопасный интерфейс на стороне Rust, реализация — на C++.

## Бэкенды

- **DirectX 12** — Windows
- **Vulkan** — кроссплатформа

## Конвейер рендеринга

Вершинный и пиксельный шейдеры, константные буферы, текстуры, материалы, рендер-цели, буфер глубины/трафарета.

Rust готовит список команд рендеринга (что нарисовать, с какими материалами, какая камера), C++ исполняет эти команды на GPU.
