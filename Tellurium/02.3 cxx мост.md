# cxx мост

Граница между Rust и C++ в Tellurium. Реализована через библиотеку **cxx** — статические, типизированные привязки с нулевым оверхедом и без сырых небезопасных указателей через границу.

## Общие типы

- `Vertex`, `Transform`, `AABB`, `MaterialData`, `TextureHandle`, `MeshHandle`

## Функции моста

- Инициализация устройства
- Отрисовка кадра
- Загрузка текстуры
- Создание меша
- Шаг физики
- Рейкаст

## Передача данных

- Строки — через типизированные `&CxxString` / `&str`
- Числа и структуры — по значению или через умные указатели `cxx::UniquePtr` / `cxx::SharedPtr`
- Сырые указатели Rust-объектов не проходят сквозь cxx границу
