# 01.2 Luau рантайм

Одна глобальная Luau VM на движок. Изоляция скриптов достигается легковесными потоками (coroutines / threads) внутри этой одной VM, а не созданием тяжелых и изолированных `lua_State`. Это гарантирует работу общей шины событий и единого API для всех скриптов.

## Принципы

- Все скрипты выполняются в главном потоке ядра (main thread), чтобы избежать гонок данных в Luau VM.
- Регистрируется движковый API: доступ к ECS, ресурсам, событиям, времени, входу, трансформации. Вызов возможен только через безопасные Rust-обёртки.
- **Песочница скриптов:** Luau не имеет прямого доступа к файловой системе, сети или памяти за пределами своего состояния. Все запросы проходят через движковый API с проверкой прав.
- Квоты: лимиты CPU-времени и памяти на один скрипт, чтобы один плохой скрипт не «повесил» движок.
- Связь Luau → Rust: обработчики событий, сигналы, функции обратного вызова.
- Связь Rust → Luau: системы ECS могут вызывать скриптовые функции (`on_update`, `on_collision`, `on_start` и т.д.).
