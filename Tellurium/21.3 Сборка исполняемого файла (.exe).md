# 21.3 Сборка исполняемого файла (.exe)

Финальный рантайм для Windows формируется следующим образом:

- Берется **предкомпилированный легковесный шаблон** `tellurium_runtime.exe` из директории `templates/windows/`.
- Шаблон инициализирует ядро Tellurium (Rust) и загружает C++ модуль через `cxx` мост — точно так же, как и в редакторе.
- Шаблон считывает привязанный или лежащий рядом файл `.telpak`, извлекает байт-код Luau, ресурсы и конфигурацию.
- Игра запускается без редактора, без исходного кода и без инструментов разработки.
