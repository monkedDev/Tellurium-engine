# 05.6 Плагины редактора

Архитектура расширений редактора Tellurium. Сторонние разработчики могут создавать кастомные окна, вкладки и инструменты.

## Расширяемость интерфейса

- Плагин может зарегистрировать новую вкладку в главном рабочем окне (рядом с Hierarchy, Inspector, Project).
- Плагин может создать плавающее окно с собственным содержимым (визуальный скриптогенератор, редактор анимаций, профилировщик).
- Плагин может добавить пункты в контекстные меню, кнопки на Toolbar, элементы в Инспектор для кастомных компонентов.
- Все элементы отрисовываются в цветовой палитре Tellurium ([[05.4 Цветовая палитра]]).

## Два типа плагинов

**Rust-плагины (глубокая интеграция):**
- Динамические библиотеки (`.dll` на Windows, `.so` на Linux).
- Полный доступ к ядру через [[02.3 cxx мост|cxx мост]]: к ECS, к Resource Manager, к Luau рантайму, к C++ графике и физике.
- Для импортеров нестандартных форматов, кастомных систем рендеринга, интеграции с внешними сервисами.

**Luau-плагины (безопасные скрипты):**
- Запускаются внутри изолированного Luau-состояния редактора.
- Ограниченный доступ: только через движковый API, без прямого доступа к файловой системе или сети.
- Для автоматизации редактора, кастомных Инспекторов, валидации сцен, генераторов узлов.

## Изоляция через Event Bus

Все взаимодействие плагинов с ядром и между собой идёт через [[Event Bus]]:
- Плагин публикует события (например, `SceneOpened`, `EntitySelected`, `ResourceReloaded`).
- Ядро и другие плагины подписываются на события и реагируют асинхронно.
- Ошибка в плагине не падает ядро — исключение перехватывается на границе плагина.
