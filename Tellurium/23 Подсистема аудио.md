# 23 Подсистема аудио (Audio Engine)

Аудио-движок Tellurium связывает Rust ECS с C++ библиотекой низкоуровневого звука (например, miniaudio, FMOD или OpenAL).

## Подразделы

- [[23.3 Связи]] — интеграция с ECS, cxx, пайплайном ассетов
