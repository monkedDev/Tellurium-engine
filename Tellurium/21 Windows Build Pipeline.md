# 21 Система экспорта проекта (Windows Build Pipeline)

Система сборки финального приложения Tellurium для Windows. Отвечает за превращение редакторского проекта в готовый к запуску `.exe` без исходного кода редактора и сырых ассетов.

## Подразделы

- [[21.1 Процесс сборки (Baking)]] — пошаговая сборка финальной игры
- [[21.2 Упаковка данных (.telpak)]] — формат монолитных бинарных архивов
- [[21.3 Сборка исполняемого файла (.exe)]] — формирование финального рантайма
- [[21.4 Экспорт зависимостей]] — динамические библиотеки Windows
- [[21.5 Разделение обязанностей]] — Rust отвечает за сборку, C++ — за рантайм
