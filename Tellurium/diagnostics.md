# diagnostics

Папка каталогов движка Tellurium, содержащая инструменты отладки и профилирования.

## Назначение

- Интеграция профилировщика (Tracy / Pix) через cxx мост
- Инструментарий в Консоли редактора (FPS, Frame Time, сущности, память, Draw Calls)
- Метрики по шагам жизненного цикла кадра
