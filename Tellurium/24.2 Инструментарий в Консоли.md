# 24.2 Инструментарий в Консоли

Отрисовка в окне **Console** следующих метрик в реальном времени:

| Метрика | Описание |
|---|---|
| FPS | Кадров в секунду |
| Frame Time | Время кадра (мс) |
| Активные сущности | Количество EntityId в мире ECS |
| Память Luau VM | Объём выделенной памяти под Luau |
| Draw Calls | Количество вызовов отрисовки графического бэкенда |
| Время физики | Длительность шага физики в C++ |
| Время ECS update | Длительность обновления ECS в Rust |
