# State Preserving

Сохранение состояния скрипта при горячей перезагрузке (Hot Reloading).

## Назначение

При изменении `.luau` файла логика скрипта заменяется на новую, но текущее состояние переменных (поля компонента, значения свойств) сохраняется. Игра не сбрасывается, сущности не пересоздаются, позиция и настройки узлов остаются прежними.

## Как работает

1. [[01.4 Менеджер ресурсов]] отслеживает изменение `.luau` файла через системные уведомления ОС
2. [[01.2 Luau рантайм]] компилирует новую версию скрипта в отдельном байт-коде, не останавливая текущую Luau VM
3. Для каждого `ScriptComponent` выполняется замена реализации функций (`on_start`, `on_update`, `on_collision` и т.д.) на новые
4. Состояние переменных сохраняется между перезагрузками
