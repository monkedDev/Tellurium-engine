# Chalcogen Blue

`#00A3E0` — Халькогеновый синий.

## Визуальная роль

Спокойный синий для элементов второго плана: подсказки, выделение текста, папки в ассет-менеджере.

## Использование

- Подсказки и всплывающие подсказки (tooltips)
- Выделение текста
- Папки в ассет-менеджере (окно Project)
- Элементы второго плана UI
