# 21.1 Процесс сборки (Baking)

Сборка финального приложения Tellurium для Windows выполняется модулем **builder** (Rust) по следующему алгоритму:

1. **Валидация проекта** — проверяется наличие файла проекта (`.tprj` или `project.toml`), целостность ссылок на сцены и ассеты.
2. **Сборка байт-кода Luau** — все `.luau` скрипты проекта компилируются в байт-код Luau. Исходный код скриптов не включается в финальный билд.
3. **Упаковка ресурсов** — содержимое директории `.telcache/` (оптимизированные текстуры, меши, шейдеры, материалы, аудио, сцены `.telsc`) собирается в монолитный архив `.telpak`.
4. **Сборка конфигурации** — файл проекта (`.tprj` / `project.toml`) сериализуется и вкладывается в `.telpak` для использования рантаймом.
5. **Отсечение редактора** — исходный код редактора, исходные ассеты (`.png`, `.fbx`, `.wav`, `.luau`), мета-файлы (`.telmeta`) и код самого редактора полностью отсекаются и не попадают в финальный билд.
6. **Формирование исполняемого файла** — к предкомпилированному шаблону `tellurium_runtime.exe` привязывается (или размещается рядом) файл `.telpak`, после чего получается готовый к запуску `.exe`.
